📌 1. Pilih Jalur Kerja Sesuai Kebutuhan Anda

Afresto AI Assistant menyediakan dua jalur utama yang sangat fleksibel untuk membantu Bapak/Ibu Guru menyusun soal tanpa mengetik ulang satu per satu:

Fitur & Kebutuhan JALUR 1 Buat Soal Otomatis via AI Gemini JALUR 2 Upload Naskah Word (.docx)
Kondisi Guru Belum memiliki naskah soal; ingin AI membuatkan draf soal baru berdasarkan materi/TP. Sudah memiliki naskah soal ujian di komputer dalam format file Microsoft Word (.docx).
Kebutuhan Kunci API Memerlukan Kunci API Gemini (Gratis 100% dari Google AI Studio). TIDAK PERLU KUNCI API (100% Bebas Kuota & Bisa Digunakan Kapan Saja).
Kecepatan Membuat 5–10 soal berkualitas dalam 10–20 detik. Membaca 30–50 soal Word beserta gambar dalam 1 detik.
Kustomisasi Bisa memilih tingkat kognitif Bloom (C1 s.d. C6/HOTS) dan membuat stimulus gambar otomatis. Mendukung formula matematika/kimia bertingkat, tabel, gambar diagram, dan bullet numbering.

🤖 2. Jalur 1: Cara Membuat & Input Soal Menggunakan AI Gemini

💡 Mengapa Menggunakan Jalur Ini? Sangat cocok saat Bapak/Ibu Guru ingin membuat variasi soal baru yang sesuai Kurikulum Merdeka, memerlukan stimulus bacaan kontekstual, atau membutuhkan variasi level kognitif (C1 Mengingat sampai C6 Mencipta) secara instan.
Langkah 1

Pasang Kunci API Gemini Gratis (Cukup 1 Kali di Awal)

1. Buka situs resmi Google: https://aistudio.google.com/app/apikey (login dengan akun Gmail/Belajar.id Anda).
2. Klik tombol "Create API key" lalu salin (copy) kode kunci yang muncul (diawali AIzaSy...).
3. Di browser Chrome, klik ikon Afresto AI Assistant → klik ikon Pengaturan (⚙️) di pojok kanan atas.
4. Tempelkan kunci ke kolom Gemini API Key → klik "Tes Koneksi" (muncul badge hijau 🟢) → klik "Simpan Kunci".

Langkah 2

Buka Halaman Form Input Soal di Portal Afresto

1. Login ke web Afresto sekolah Anda di Google Chrome.
2. Buka menu: Evaluasi → Butir Soal → Tulis Soal Baru.
3. Buka panel samping ekstensi. Panel akan otomatis mendeteksi nama Mata Pelajaran dan Kelas dengan status hijau: 🟢 Halaman Input Soal Afresto Aktif.

Langkah 3

Isi Tujuan Pembelajaran (TP) & Pilih Tipe Soal

1. Pada tab "Generate via AI Gemini", ketikkan materi atau Tujuan Pembelajaran (contoh: "Perangkat keras komputer dan fungsinya").
2. Tentukan jumlah soal dan centang tipe soal yang diinginkan (Pilihan Ganda, Benar/Salah, Menjodohkan, Isian, atau Uraian).
3. Pilih Tingkat Kognitif (misal: C3 Aplikasi, C4 Analisis/HOTS, atau Campuran Seimbang).
4. (Opsional) Aktifkan saklar "Generate Stimulus Gambar Edukatif" jika soal membutuhkan diagram ilustrasi visual.
5. Klik tombol biru: "✨ Generate Paket Soal via Gemini".

Langkah 4

Tinjau Antrean Soal & Input Otomatis ke Afresto

1. Butir soal yang dihasilkan AI akan muncul rapi di daftar Antrean Soal (Playlist) lengkap dengan kunci jawaban dan pembahasannya.
2. Bapak/Ibu dapat mengedit teks soal atau kunci jawaban kapan saja dengan mengeklik tombol ✏️ Edit.
3. Klik tombol hijau besar di bagian bawah: "🚀 Input Otomatis ke Afresto".
4. Asisten akan otomatis mengisi formulir web Afresto, memilih opsi kunci jawaban, mengunggah gambar stimulus (jika ada), menekan tombol Simpan, dan beralih ke butir berikutnya sampai tuntas!

📄 3. Jalur 2: Cara Upload Naskah Word (.docx) ke Portal Afresto

✨ Keunggulan Jalur Word: 100% Gratis & Tanpa Kuota API Key! Sangat ideal untuk memasukkan naskah ujian Penilaian Akhir Semester (PAS), Sumatif Akhir Tahun (SAT), atau bank soal sekolah yang sudah Bapak/Ibu miliki di laptop.
Langkah 1

Gunakan Template Resmi (TEMPLATE_SOAL_AFRESTO.docx)

1. Di panel ekstensi, klik tombol "Unduh Template Naskah Word" (atau gunakan berkas TEMPLATE_SOAL_AFRESTO.docx yang ada di dalam paket rilis).
2. Buka berkas tersebut di Microsoft Word. Anda cukup mengganti isi teks soal dan opsi jawaban sesuai materi ujian Anda.

Langkah 2

Aturan Format Penulisan di Word yang Terbaca Otomatis

Sistem parser Afresto AI Assistant sangat pintar dan fleksibel mendukung format kebiasaan guru:

  • Bullet & Numbering: Bebas menggunakan tombol penomoran otomatis Word (Word Auto-Numbering / Bullets) maupun nomor ketikan manual (1., 2., A., B.).
  • Format Kunci Jawaban: Cukup tulis Kunci: B di bawah opsi, ATAU cetak tebal (bold) pada huruf opsi yang benar (contoh: **B. HTTPS**), ATAU tulis dalam kurung di akhir baris soal (contoh: ... adalah (B)).
  • Gambar & Rumus: Sisipkan gambar diagram (Insert Picture) atau rumus matematika/kimia Word Equation (OMML). Keduanya akan otomatis terbaca dan diubah menjadi tampilan siap pakai di Afresto!
Langkah 3

Upload File Word ke Ekstensi

1. Pada panel samping ekstensi, klik tab "Impor Naskah Word (.docx)".
2. Klik tombol "Pilih File Naskah Word", lalu cari dan pilih dokumen Word ujian Anda dari laptop.
3. Dalam hitungan detik, seluruh soal (1 sampai puluhan soal) langsung diekstrak rapi ke dalam daftar antrean!

Langkah 4

Periksa Indikator Pre-Flight & Mulai Input Otomatis

1. Periksa kotak status di bawah judul: jika muncul 🟢 Siap Input (100% Valid), berarti seluruh soal telah lengkap opsi dan kuncinya.
2. Pastikan halaman web portal Afresto Anda berada di formulir: Evaluasi → Butir Soal → Tulis Soal Baru.
3. Klik tombol hijau besar: "🚀 Input Otomatis ke Afresto".
4. Ekstensi akan menginputkan seluruh soal Word Anda satu per satu ke Afresto dengan aman, tepat, dan bebas salah klik!

📚 4. Ragam Contoh Format 6 Tipe Soal Resmi di Word

Berikut adalah acuan penulisan untuk 6 tipe soal resmi yang dapat langsung terbaca sempurna oleh Afresto AI Assistant:

1. Pilihan Ganda (PG Tunggal) 1. Protokol jaringan yang mentransfer web terenkripsi SSL/TLS adalah... A. HTTP B. HTTPS C. FTP D. SMTP E. Telnet Kunci: B Pembahasan: HTTPS menggunakan enkripsi SSL/TLS pada port 443.
2. Pilihan Ganda Kompleks (Multi-Kunci Jawaban) 2. Manakah sistem operasi berikut yang bersifat open-source? (Pilih 3 benar) A. Ubuntu Linux B. Windows 11 C. Debian GNU/Linux D. Fedora Linux E. macOS Kunci: A, C, D
3. Benar / Salah (Format Pernyataan Berbutir) 3. Tentukan nilai kebenaran dari setiap pernyataan keamanan siber berikut! A. Mengaktifkan 2FA mempersulit akun diretas. (Benar) B. Password aman cukup menggunakan 4 angka tanggal lahir. (Salah) C. Phishing adalah penipuan tautan palsu pencuri data. (Benar) Kunci: A: Benar, B: Salah, C: Benar
4. Menjodohkan / Mencocokkan (Format Pasangan Premis - Respon) 4. Pasangkanlah perangkat jaringan di sebelah kiri dengan fungsi utamanya! 1. Router - Mengarahkan paket data antar subnet jaringan yang berbeda 2. Switch - Menghubungkan perangkat komputer dalam satu Local Area Network 3. Access Point - Memancarkan sinyal gelombang radio koneksi Wi-Fi nirkabel Kunci: 1-A, 2-B, 3-C
5. Isian Singkat (Mendukung Alternatif Jawaban dengan Garis Miring) 5. Presiden pertama Republik Indonesia yang membacakan teks proklamasi adalah... (Ir. Soekarno) Kunci: Ir. Soekarno / Soekarno / Bung Karno
6. Uraian / Essay (Dilengkapi Rubrik Penilaian) 6. Jelaskan 2 kelebihan utama kabel serat optik (fiber optic) dibandingkan kabel tembaga UTP! Kunci: Rubrik Penilaian: 1. Kecepatan transfer gigabit lebih tinggi, 2. Kebal gangguan gelombang elektromagnetik.

⭐ 5. Fitur Bantuan Ekstra Penunjang Produktivitas Guru

🎮 Studio Simulasi & Test-Drive (Uji Coba Mengerjakan Soal)

Bapak/Ibu ingin mencoba menjawab soal seperti tampilan siswa sebelum diinput ke Afresto? Klik tombol "🎮 Studio Preview" di panel. Anda dapat mensimulasikan kuis interaktif, memeriksa kebenaran kunci, dan mencetak lembar soal ke kertas fisik atau PDF lembar ujian!

🔄 Tombol Urutkan Semula & Reset Status

Jika urutan soal sempat teracak atau Anda ingin mengulang penginputan dari awal:
• Klik tombol "Urutkan": Mengembalikan posisi seluruh kartu soal persis ke urutan nomor aslinya (1..N).
• Klik tombol "Reset": Mengembalikan status seluruh soal menjadi siap input kembali.

☀️/🌙 Tema Ganda (Kertas Gading Hangat & Mode Gelap)

Mengetik soal berjam-jam membuat mata lelah? Klik tombol matahari/bulan di kanan atas. Mode terang dirancang dengan palet Humanist Warm Paper (kertas gading klasik yang menyejukkan mata), sedangkan mode gelap melindungi mata saat menyusun soal di malam hari.

⚡ Update Otomatis 1-Klik (UPDATE_APLIKASI.bat)

Jika sekolah merilis versi pembaruan aplikasi, Anda tidak perlu mengulang instalasi dari nol. Cukup klik 2x file UPDATE_APLIKASI.bat di folder ekstensi, lalu klik ikon panah putar (Refresh 🔄) di menu chrome://extensions. Versi terbaru langsung aktif dalam 3 detik!

❓ 6. Tanya Jawab & Bantuan Cepat (FAQ)

Tanya: Tombol "Input Otomatis ke Afresto" berwarna abu-abu dan tidak bisa diklik. Mengapa?
Jawab: Tombol sengaja dikunci jika browser Anda belum membuka formulir soal Afresto. Buka portal Afresto → klik menu Evaluasi → Butir Soal → Tulis Soal Baru. Begitu form terbuka, tombol akan otomatis menyala hijau terang!
Tanya: Apakah akun portal Afresto dan data pribadi saya aman?
Jawab: 100% AMAN. Ekstensi ini berjalan sepenuhnya secara lokal di browser komputer Anda (Client-Side). Asisten hanya membantu mengetikkan teks ke formulir seperti asisten pribadi, tanpa pernah mengirimkan kata sandi Anda ke server luar mana pun.
Tanya: Bagaimana jika internet terputus di tengah proses input otomatis?
Jawab: Jangan khawatir! Ekstensi memiliki sistem proteksi anti-duplikasi. Butir soal yang sudah tersimpan ditandai centang hijau (✅ Injected). Saat internet kembali online, cukup klik tombol input lagi, dan asisten akan melanjutkan hanya soal-soal yang belum tersimpan.
Tanya: Apakah saya harus online terus saat menginput soal dari Word?
Jawab: Membaca dan mem-parsing soal dari berkas Word bekerja 100% secara offline tanpa internet. Anda hanya butuh internet untuk membuka portal web Afresto sekolah Anda saat mengklik tombol input otomatis.
