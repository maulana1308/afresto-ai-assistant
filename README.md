# 🏛️ Afresto AI Assistant (Chrome Extension v3.0.0)

Asisten AI Cerdas Pembuat Soal Asesmen dan Materi Pembelajaran Berstandar BSKAP Kemendikbudristek No. 032/H/KR/2024 untuk Portal Afresto.

## 🚀 Fitur Utama v3.0.0:
1. **Modul Soal Evaluasi:** Pembuatan 6 tipe soal (PG, PG Kompleks, Benar/Salah, Menjodohkan, Isian, Uraian) dengan stimulus kontekstual & kunci jawaban terverifikasi.
2. **Modul Materi & Bahan Ajar:** Pembuatan artikel materi pembelajaran mendalam (Apersepsi, Konsep Inti, Studi Kasus, Rangkuman) beserta pertanyaan refleksi HOTS.
3. **Ilustrasi Visual & Vektor SVG:** Engine diagram vektor ilmiah presisi bebas halusinasi untuk biologi, fisika, dan matematika.
4. **Injeksi Form Tanpa Auto-Save:** Ekstensi mengisi judul, konten, dan tugas, sementara guru bebas mengatur jadwal dan mengklik tombol Simpan sendiri.
5. **Sistem Pembaruan Otomatis 1-Klik:** Terhubung langsung ke GitHub Releases melalui file `UPDATE_APLIKASI.bat`.
